    Parameters¶

    Set parameters on the command line with two dashes (--cellpose_diameter 40) or in a params file passed with -params-file. Do not set them in a -c config file.

    Parameters marked hidden are left out of --help and the Seqera Platform launch form unless hidden parameters are shown (--show_hidden). They work the same as other parameters.

    This page is generated from nextflow_schema.json.

    Input/output options¶

    Define where the pipeline should find input data and save output data.

    Parameter Type Default Description
    input (required) string Path to the samplesheet (CSV or YAML) that lists the images to process.
    outdir (required) string The output directory where the results will be saved. You have to use absolute paths to storage on Cloud infrastructure.
    email string Email address for completion summary.

    input¶

    One row per image. Required columns: sample and tiff. See the Samplesheet page of the documentation for every column.

    email¶

    The pipeline sends a summary e-mail to this address when the run finishes. You can set it in ~/.nextflow/config instead of on the command line.

    Background subtraction options¶

    Parameters used for background subtraction.

    Parameter Type Default Description
    remove_markers string TRITC,Cy5 Comma-separated channel names to remove from the background-subtracted image. Names are case sensitive.

    Combine options¶

    Parameters used for combining membrane channels.

    Parameter Type Default Description
    combine_method string: max, norm_mean max How to combine several membrane channels into one. max: the per-pixel maximum. norm_mean: the mean of the channels after rescaling each to its own 50th-99.5th percentile.

    combine_method¶

    Used when membrane_channels lists more than one channel. max is used by Mesmer, Cellpose and CellSAM. norm_mean is used by Cellpose and CellSAM only; a sample that runs Mesmer with norm_mean and more than one membrane channel stops the run at startup. With max, a dim marker is hidden wherever a brighter marker has signal; norm_mean puts every marker on the same scale. See Combining membrane channels.

    Cell processing options¶

    Parameters used for cell processing.

    Parameter Type Default Description
    use_whole_cell_only boolean true Use only the whole-cell segmentation to process cells (skip nuclear segmentation).

    use_whole_cell_only¶

    Defaults to true: only the whole-cell segmentation is used to process cells. Nuclei are not segmented and nuclear measurements are not produced; cell, erosion, and expansion measurements are kept. Set to false to also segment nuclei and measure them.

    SOPA options¶

    Parameters used by SOPA for image patching.

    Parameter Type Default Description
    technology string: ome_tif ome_tif Image type for the sopa conversion. Only ome_tif is supported.
    patch_width_pixel integer 3000 Width and height of each square patch, in pixels, for Cellpose segmentation.
    patch_overlap_pixel integer 250 Overlap between neighbouring patches, in pixels. Set it to at least the diameter of the largest cell.

    Cellpose options¶

    Parameters used by Cellpose for the cell segmentation.

    Parameter Type Default Description
    cellpose_diameter integer 30 Expected cell diameter in pixels. Cellpose resizes the image by 30 / diameter before segmentation.
    cellpose_min_area number 100 Discard cells smaller than this many square pixels. Higher keeps fewer cells; 0 keeps every mask.
    cellpose_flow_threshold number 0.4 Maximum flow error allowed for a mask to be kept. Higher finds more cells, including ill-shaped ones; lower keeps fewer, better-formed ones.
    cellpose_cellprob_threshold number 0.0 Cutoff on Cellpose's per-pixel cell probability. Lower finds more and larger cells; higher finds fewer and smaller ones.
    cellpose_model_type (hidden) string Retired. Cellpose 4 ignores --model-type; use cellpose_pretrained_model instead.
    cellpose_pretrained_model string cpsam_v2 Cellpose model to segment with: cpsam_v2 (default), cpsam, cpdino, cpdino-vitb, or a path to a custom model.
    cellpose_models_dir string Directory holding pre-staged Cellpose model weights. If set, the pipeline uses it instead of downloading them.

    cellpose_diameter¶

    Cellpose-SAM models were trained on cell diameters from 7.5 to 120 pixels (mean 30), so the default of 30 suits most data and means no resizing.

    • Set the real diameter if your cells are outside 7.5-120 pixels.
    • A larger value (for example 90) shrinks the image and makes the run faster, but small objects are resolved less well.

    This parameter does not remove any cells. Use cellpose_min_area to remove small objects. A value of 0 means no resizing; Cellpose 4 has no automatic diameter estimate.

    cellpose_min_area¶

    Applied by sopa to each patch during segmentation. The unit is pixels², not µm², so it does not change with pixel_size_microns. At 0.28 µm/pixel (COMET), 100 pixels² is 7.8 µm², about a 3.2 µm diameter disc.

    cellsam_min_area uses the same unit and defaults to 200. mesmer_min_nuclei_area is a separate filter on nuclei.

    cellpose_flow_threshold¶

    Cellpose recomputes the flows each mask implies and compares them with the flows the network predicted. Masks with a mean squared error above this value are removed. This filter acts on shape only.

    • Raise it (0.6, 0.8) if visible cells are missing.
    • Lower it (0.2, 0.3) if you get ragged, ill-shaped masks.
    • 0 turns the check off.

    The default 0.4 is Cellpose's default.

    cellpose_cellprob_threshold¶

    Pixels above this value are used to build cells, so it changes which cells are found and where each cell boundary falls. A change here changes cell areas and therefore every per-cell intensity.

    The value is not a probability between 0 and 1. It is a logit: the useful range is about -6 to +6, and 0 is the midpoint.

    • Lower it (-1, -2) to find faint cells and make cells larger.
    • Raise it (1, 2) to stop segmenting background and make cells smaller.

    The default 0.0 is Cellpose's default.

    cellpose_model_type¶

    Cellpose >=4.0.1 logs model_type argument is not used in v4.0.1+. Ignoring this argument, and sopa only reads it on the cellpose<4 code path, so it never had any effect on a v4 run. Setting it now raises an error rather than being silently discarded.

    cellpose_pretrained_model¶

    Built-in models (cellpose 4.2.1.1):

    • cpsam_v2: default; the current Cellpose-SAM model.
    • cpsam: the previous Cellpose-SAM model. Use it to reproduce results from before cellpose 4.2.
    • cpdino: DINOv3 backbone (ViT-L).
    • cpdino-vitb: smaller DINOv3 backbone (ViT-B).

    Any other value is treated as a path to a custom model and must exist; the pipeline checks this at startup. Built-in models are downloaded once per run, or read from cellpose_models_dir if set. See CITATIONS.md for the DINOv3 licence terms.

    cellpose_models_dir¶

    A directory that holds the Cellpose model cache (for example a cpsam_v2 file). Use it when compute nodes have no internet access. The directory must exist and must not be under /opt.

    Cellpose preprocessing options¶

    Intensity preprocessing applied before Cellpose segmentation.

    The defaults make the pipeline match Cellpose's own preprocessing: rescale each patch to its 1st and 99th percentiles and nothing else. sopa's gaussian filter and CLAHE are turned off. To restore sopa's behaviour, set cellpose_clip_limit to 0.2 and cellpose_gaussian_sigma to 1. See the Cellpose preprocessing page of the documentation for the measurements behind these defaults.

    Parameter Type Default Description
    cellpose_tile_norm_blocksize (hidden) integer 0 Block size in pixels for Cellpose's tile-local intensity normalisation. 0 uses Cellpose's whole-patch default.
    cellpose_clip_limit (hidden) number 0 sopa's CLAHE clip limit, applied before Cellpose. Defaults to 0 in this pipeline, disabling CLAHE; null restores sopa's default of 0.2.
    cellpose_clahe_kernel_size (hidden) integer Kernel size in pixels for sopa's CLAHE. Unset uses skimage's default of patch.shape // 8, which scales with patch_width_pixel.
    cellpose_gaussian_sigma (hidden) number 0 Sigma for sopa's gaussian smoothing, applied before Cellpose. Defaults to 0 in this pipeline, disabling it; null restores sopa's default of 1.

    cellpose_tile_norm_blocksize¶

    When greater than 0, Cellpose computes the 1st/99th percentiles separately for each block of this size inside the patch instead of once for the whole patch.

    Use a block much larger than a cell. At 0.28 µm/pixel, 512 pixels is 143 µm (about 17 nuclear diameters). Small blocks (for example 128 pixels) can contain no nuclei in sparse tissue; their noise is then stretched to the full intensity range and results get worse.

    cellpose_clip_limit¶

    sopa applies CLAHE (skimage.exposure.equalize_adapthist) to each patch before Cellpose. Cellpose itself has no CLAHE step and its models were not trained with it. 0 turns CLAHE off. With CLAHE on, results change with patch_width_pixel, because the CLAHE kernel size is derived from the patch size.

    cellpose_clahe_kernel_size¶

    If unset, skimage uses 1/8 of the patch height and width: 375 pixels at patch_width_pixel 3000. Setting a fixed value stops the kernel size changing with the patch size. Has no effect while cellpose_clip_limit is 0.

    cellpose_gaussian_sigma¶

    sopa applies a gaussian filter to each patch before Cellpose. Cellpose applies no smoothing by default. 0 turns the filter off. Raise it only if your images are noisy enough to need smoothing before segmentation.

    Mesmer options¶

    Parameters used by the MesmerSegmentation tool.

    Parameter Type Default Description
    mesmer_segmentation_level integer Segmentation level passed to Mesmer as --segmentation-level (legacy option). Unset by default.
    mesmer_maxima_threshold number 0.1 Mesmer maxima threshold. Lower values give more cells; higher values give fewer cells.
    mesmer_interior_threshold number 0.3 Mesmer interior threshold. Higher values give smaller nuclei and cells.
    mesmer_maxima_smooth number 0 Smoothing applied to Mesmer's maxima signal. Higher values give more regular shapes.
    mesmer_min_nuclei_area number 40 Minimum nucleus area in pixels². Smaller nuclei are removed by Mesmer.
    mesmer_remove_border_cells boolean true Remove cells that touch the image border.
    mesmer_pixel_expansion integer 3 Number of pixels to expand each Mesmer cell after segmentation.
    mesmer_padding integer 0 Number of pixels to crop from each side of the image before Mesmer segmentation.
    mesmer_transpose_mask boolean false Transpose the Mesmer output mask. Enable this only if the mask is flipped relative to the image.

    CellSAM options¶

    Parameters used by CellSAM for foundation model cell segmentation.

    Parameter Type Default Description
    cellsam_bbox_threshold number 0.4 Confidence threshold for CellSAM cell detections. Lower values (0.3-0.4) find more cells on images unlike the training data.
    cellsam_block_size integer 600 Tile size in pixels for whole-slide CellSAM processing.
    cellsam_overlap integer 250 Overlap between CellSAM tiles, in pixels. Set it to at least the typical cell diameter.
    cellsam_iou_depth integer 250 Distance in pixels searched for duplicate cells at tile boundaries.
    cellsam_iou_threshold number 0.5 IoU above which two overlapping cells at a tile boundary are merged.
    cellsam_use_wsi boolean true Process the image in tiles (whole-slide mode). Required for large images.
    cellsam_gauge_cell_size boolean false Run a first CellSAM pass to estimate cell size before segmentation.
    cellsam_low_contrast_enhancement boolean false Apply contrast enhancement before segmentation, for low-contrast images.
    cellsam_model_path string Path to custom CellSAM model weights. If unset, the CellSAM generalist model is used (v1.2 when DEEPCELL_ACCESS_TOKEN is set).
    cellsam_min_area integer 200 Remove cells smaller than this many pixels². 0 keeps every cell.
    cellsam_remove_border_cells boolean true Remove CellSAM cells that touch the image edge.

    cellsam_min_area¶

    CellSAM counts each cell's pixels and applies the filter once, after the tiles are merged. The unit is pixels², not µm². At 0.28 µm/pixel, 200 pixels² is 15.7 µm². Cells with an area equal to the threshold are kept.

    cellpose_min_area measures the area of the cell polygon instead. On test cells the polygon area was 0.93-1.00 times the pixel count (median 0.99), so at the same value the two filters remove almost the same cells. cellpose_min_area defaults to 100.

    cellsam_remove_border_cells¶

    Cells cut by the image edge are incomplete, so they are removed by default. Set to false to keep them.

    KRONOS2 embedding options¶

    Options for KRONOS2 per-cell foundation-model embeddings

    KRONOS2 is a foundation model for multiplex spatial proteomics. These parameters control the optional step that adds a 768-value embedding to every cell after cell measurement.

    Parameter Type Default Description
    enable_kronos boolean false Enable KRONOS2 per-cell embedding extraction.
    kronos_model_path string Path to a full KRONOS2 snapshot directory, or a Hugging Face repo id.
    kronos_patch_size integer 64 Size of cell-centered patches to extract for KRONOS inference.
    kronos_batch_size integer 16 Batch size for inference. KRONOS2 runs fp32 and cuBLAS picks batch-dependent kernels, so this shifts embeddings slightly; 16 reproduces the published values.
    kronos_num_workers integer 4 Number of parallel DataLoader workers for loading and preprocessing cell patches.
    kronos_max_value number Override the intensity divisor. Unset derives it from the image dtype (uint8=255, uint16=65535, float=400), matching KRONOS2 itself.
    kronos_marker_mapping string JSON file, or an inline JSON object, that maps channel names to KRONOS2 marker names, e.g. {"Collagen 4": "COLLAGENiv"}.
    kronos_exclude_markers string Comma-separated channel names that KRONOS2 does not read, e.g. 'Autofluorescence'. Other steps still use these channels.
    kronos_nuclear_marker string Channel that KRONOS2 treats as its DAPI channel. Defaults to the samplesheet nuclear_channel.
    kronos_isolate_cell boolean true Zero pixels outside the target cell so each embedding describes that cell rather than its surrounding neighbourhood.
    kronos_allow_novel_defaults boolean false Continue when a channel name is not in the KRONOS2 vocabulary. That channel is normalised with default statistics. Off by default, so the run fails instead.

    enable_kronos¶

    Set to true to compute KRONOS2 embeddings after cell measurement. Requires kronos_model_path.

    kronos_model_path¶

    Request access to MahmoodLab/KRONOS2 on Hugging Face, then download the full snapshot:

    hf download MahmoodLab/KRONOS2 --local-dir /path/to/KRONOS2 --exclude "demo_image/*"

    A partial download does not work, because the loader imports the dinov2 package bundled in the snapshot. Do not store the snapshot under /opt.

    kronos_patch_size¶

    Side length in pixels of the square patch centred on each cell. Larger patches include more surrounding tissue and take longer.

    kronos_batch_size¶

    Number of cell patches per GPU batch. Larger batches are faster and use more GPU memory. Embeddings change very slightly with batch size; 16 reproduces the published values.

    kronos_num_workers¶

    Number of CPU processes that read and prepare patches while the GPU runs. 0 reads in the main process. Set it to the number of CPUs allocated to the task.

    kronos_marker_mapping¶

    KRONOS2 matches marker names exactly, ignoring separators (CD-8, CD_8 and CD8 match). There is no alias or fuzzy matching, so a spelling variant such as Cytokeritin does not match CYTOKERATIN. The run fails if any channel does not match, unless kronos_allow_novel_defaults is true.

    The mapping changes only the names given to KRONOS2. Channel names in the image and the GeoJSON are not changed. A value that is neither an existing file nor valid JSON fails the run.

    kronos_exclude_markers¶

    Use it for channels that are not markers: autofluorescence, blanks, empty cycles. The channel stays in the image and keeps its cell measurements.

    • Names are case sensitive and are matched against the image's channel names before kronos_marker_mapping is applied.
    • A name that matches no channel fails the run.
    • The nuclear channel cannot be excluded.
    • Excluding a channel changes every cell's embedding. Use the same list for every image in a cohort.

    Cell measurement options¶

    Parameters used for cell measurement.

    Parameters for the cell measurement step (cellmeasurement-py).

    Parameter Type Default Description
    enable_measurements boolean true Enable cell measurement step.
    percentiles string 70,80,90,95,99 Comma-separated list of percentiles to calculate for each marker (e.g. 80,90,95,99).
    erosion_steps boolean true Measure intensity in 5 equal-area erosion bins working inward from the cell/nucleus boundary.
    expansion_steps boolean true Measure intensity in 5 equal-area annular bins dilated 20 µm outward from the cell boundary (distance computed from pixel_size_microns).
    environment_expansion boolean true Measure a 20 µm pericellular 'Environment' compartment (distance computed automatically from pixel_size_microns).
    pixel_size_microns number 0.28 Pixel size in microns.
    estimate_cell_boundary_dist integer 3 For a nucleus with no matching whole-cell ROI, expand the nucleus by this many pixels to make the cell.
    neighbors integer 0 Number of nearest neighbours used for neighbourhood features. 0 turns them off.
    gzip_geojson (hidden) boolean true Gzip-compress the output GeoJSON files. Produces .geojson.gz instead of .geojson.
    dist_threshold number 10.0 Maximum centroid distance in pixels for matching a nucleus to a whole-cell ROI.
    downsample_factor number 1.0 Downsample factor applied to the image and masks before measurement (1 = no downsampling).
    tile_size integer 2048 Tile size for large image measurement calculations.
    tile_overlap integer 200 Tile overlap region in pixels. Should encompass typical cell size.
    geometry_checkpoint_dir string Directory for resumable polygon-extraction checkpoints.
    geometry_batch_size integer 2000 Cells per polygon-extraction batch, and the checkpoint granularity.

    enable_measurements¶

    Set to false to skip intensity and shape measurements. Cell outlines are still written to the GeoJSON. Skipping saves time on large images.

    percentiles¶

    Each value must be between 0 and 100. Requires enable_measurements to be true.

    erosion_steps¶

    Splits each cell (and nucleus) into 5 rings of approximately equal area, from the boundary inward, and measures mean and median intensity in each ring. Requires enable_measurements to be true.

    expansion_steps¶

    Splits the 20 µm zone outside each cell into 5 rings of approximately equal area and measures mean and median intensity in each ring. The distance in pixels is computed from pixel_size_microns. Requires enable_measurements to be true.

    environment_expansion¶

    Measures mean, median, min, max and standard deviation of every channel in the zone from the cell boundary to 20 µm outside it, as one region (Environment_20um). The distance in pixels is computed from pixel_size_microns.

    pixel_size_microns¶

    COMET: 0.28. MIBI: 0.390625. OPAL: 0.4964.

    neighbors¶

    For each cell, the mean of every numeric measurement over its nearest neighbours (up to this number, within 20 µm of the cell centroid) is added as Neighbours: Mean: <measurement>. Typical values: 5-10.

    gzip_geojson¶

    Writes .geojson.gz instead of .geojson. Whole-slide GeoJSON files can exceed 100 GB uncompressed; gzip usually reduces them 10-20 times. The import_large_geojson pipeline reads the compressed files directly.

    dist_threshold¶

    A nucleus and a whole-cell ROI whose centroids are further apart than this are not matched. Unmatched nuclei get a cell boundary made by expanding the nucleus (see estimate_cell_boundary_dist).

    downsample_factor¶

    An integer of 2 or more downsamples the image (block mean) and masks (block max) before measurement. Values below 2 mean no downsampling. Area and length measurements are scaled back to full-resolution units.

    tile_size¶

    Measurements are computed on tiles in parallel. Aim for 2-4 times more tiles than CPUs.

    tile_overlap¶

    Set it to at least the diameter of the largest cell, so every cell is complete in at least one tile.

    geometry_checkpoint_dir¶

    Each completed batch of cell polygons is written here, so a CELLMEASUREMENT task that is killed resumes from the last completed batch. The directory must be outside the Nextflow work directory. Checkpoints are not deleted automatically. Leave unset to turn checkpointing off.

    geometry_batch_size¶

    Smaller batches are checkpointed more often but add overhead. A killed task loses at most one batch per worker.

    Mask smoothing options¶

    Parameters for optional mask smoothing before cell measurement.

    Enable mask smoothing to reduce polygon complexity in segmentation masks. This can prevent StackOverflowError in QuPath's GeoJSON export when cell ROIs have overly complex/jagged boundaries.

    Parameter Type Default Description
    smooth_masks (hidden) boolean false Enable mask smoothing before cell measurement.
    smooth_method (hidden) string: morphological, shapely morphological Smoothing algorithm: 'morphological' (disk close+open) or 'shapely' (Douglas-Peucker polygon simplification).
    smooth_kernel_size (hidden) integer 2 Disk radius in pixels for morphological smoothing.
    smooth_n_workers (hidden) integer 8 Number of worker processes for mask smoothing.
    smooth_chunksize (hidden) integer 200 Number of labels each smoothing worker processes at a time.
    smooth_tolerance (hidden) number 1 Douglas-Peucker tolerance in pixels for shapely smoothing.
    smooth_min_area (hidden) number 0 Minimum polygon area in pixels² kept after shapely smoothing.

    smooth_masks¶

    Smooths the label masks before cell measurement to reduce the number of polygon vertices. Use it if QuPath fails with StackOverflowError when exporting or loading the GeoJSON. Choose the method with smooth_method.

    smooth_method¶

    morphological applies a binary close then open with a disk of radius smooth_kernel_size. shapely simplifies each cell outline with the Douglas-Peucker algorithm (tolerance smooth_tolerance), which reduces the vertex count directly.

    smooth_kernel_size¶

    Larger values give smoother outlines but can merge neighbouring cells.

    smooth_n_workers¶

    Set it to the number of CPUs allocated to the SMOOTHMASKS task.

    smooth_chunksize¶

    Use larger values for many small cells and smaller values for fewer large cells.

    smooth_tolerance¶

    Higher values give simpler outlines with fewer vertices. Start with 1.

    smooth_min_area¶

    Removes fragments created by simplification. 0 keeps every cell.

    Institutional config options¶

    Parameters used to describe centralised config profiles. These should not be edited.

    The centralised nf-core configuration profiles use a handful of pipeline parameters to describe themselves. This information is then printed to the Nextflow log when you run a pipeline. You should not need to change these values when you run a pipeline.

    Parameter Type Default Description
    custom_config_version (hidden) string master Git commit id for Institutional configs.
    custom_config_base (hidden) string https://raw.githubusercontent.com/nf-core/configs/master Base directory for Institutional configs.
    config_profile_name (hidden) string Institutional config name.
    config_profile_description (hidden) string Institutional config description.
    config_profile_contact (hidden) string Institutional config contact information.
    config_profile_url (hidden) string Institutional config URL link.

    custom_config_base¶

    If you're running offline, Nextflow will not be able to fetch the institutional config files from the internet. If you don't need them, then this is not a problem. If you do need them, you should download the files from the repo and tell Nextflow where to find them with this parameter.

    Generic options¶

    Less common options for the pipeline, typically set in a config file.

    These options are common to all nf-core pipelines and allow you to customise some of the core preferences for how the pipeline runs.

    Typically these options would be set in a Nextflow config file loaded for all pipeline runs, such as ~/.nextflow/config.

    Parameter Type Default Description
    version (hidden) boolean false Display version and exit.
    publish_dir_mode (hidden) string: symlink, rellink, link, copy, copyNoFollow, move copy Method used to save pipeline results to output directory.
    email_on_fail (hidden) string Email address for completion summary, only when pipeline fails.
    plaintext_email (hidden) boolean false Send plain-text email instead of HTML.
    monochrome_logs (hidden) boolean false Do not use coloured log outputs.
    hook_url (hidden) string Incoming hook URL for messaging service
    validate_params (hidden) boolean true Boolean whether to validate parameters against the schema at runtime
    pipelines_testdata_base_path (hidden) string https://raw.githubusercontent.com/nf-core/test-datasets/ Base URL or local path to location of pipeline test dataset files
    deepcell_cache_dir string Base directory for caching DeepCell/CellSAM model weights. The current username is appended automatically.
    container_cache_dir string Directory for the Apptainer/Singularity image cache. Set this on any cluster where $HOME has a quota.

    publish_dir_mode¶

    The Nextflow publishDir option specifies which intermediate files should be saved to the output directory. This option tells the pipeline what method should be used to move these files. See Nextflow docs for details.

    email_on_fail¶

    An email address to send a summary email to when the pipeline is completed - ONLY sent if the pipeline does not exit successfully.

    hook_url¶

    Incoming hook URL for messaging service. Currently, MS Teams and Slack are supported.

    deepcell_cache_dir¶

    Set this to redirect the DeepCell model cache away from the home directory. The current username is resolved at runtime and appended, so models are cached at {deepcell_cache_dir}/{username}/.deepcell/models/. Set to null to use $HOME instead.

    container_cache_dir¶

    Sets apptainer.cacheDir and singularity.cacheDir, so converted .img files are written here rather than under the work directory. This covers only half of a pull: Apptainer unpacks the OCI layers it converts from into $APPTAINER_CACHEDIR (default ~/.apptainer/cache), which Nextflow cannot set because it pulls images from its own process rather than from a task. Export APPTAINER_CACHEDIR and SINGULARITY_CACHEDIR to the same filesystem before launching; the pipeline errors at startup if this parameter is set without them.
