# Troubleshooting

Find the failing task in the Nextflow log, then look in its work directory
(shown in the error) at `.command.err`, `.command.out` and `.command.log`.

## Errors and fixes

| Message                                                                           | Cause                                                                                                                                      | Fix                                                                                                                                                                          |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Nextflow version ... does not match workflow required version: >=24.04.2`        | Nextflow is older than 24.04.2. At WEHI, the default `nextflow` module is 23.10.0.                                                         | Use Nextflow 24.04.2 or later. At WEHI: `module load nextflow/25.10.0`.                                                                                                      |
| `disk quota exceeded` while pulling a Singularity or Apptainer image              | Apptainer writes image layers to `~/.apptainer/cache`, and the home directory is full.                                                     | Export `APPTAINER_CACHEDIR` and `SINGULARITY_CACHEDIR` to scratch before starting Nextflow. See [Caches on a cluster](usage.md#caches-on-a-cluster).                         |
| `container_cache_dir is set, but the container layer cache is still under $HOME`  | `--container_cache_dir` is set but `APPTAINER_CACHEDIR` is unset or under `$HOME`.                                                         | Run the `export` commands printed with the error, then start the pipeline again.                                                                                             |
| Warning: `Container images will be cached under $HOME`                            | Apptainer or Singularity is used and `APPTAINER_CACHEDIR` is unset or under `$HOME`.                                                       | Export `APPTAINER_CACHEDIR` to scratch. The run continues if you do not.                                                                                                     |
| Image pull fails with exit status 143                                             | The pull took longer than the timeout. The pipeline sets a 1-hour pull timeout.                                                            | Run again with `-resume`, or pull the images in advance into `NXF_SINGULARITY_CACHEDIR`.                                                                                     |
| `sopa: command not found`                                                         | A staged input is under `/opt`. The host `/opt` is mounted over the container's `/opt`, which hides its software.                          | Move the file or directory out of `/opt`. The pipeline rejects `--cellpose_models_dir` under `/opt` at startup.                                                              |
| `/usr/bin/env: 'python3': No such file or directory`                              | Same cause: an input such as `--kronos_model_path` is under `/opt`.                                                                        | Move the input out of `/opt`.                                                                                                                                                |
| HTTP 429 or a truncated download of Cellpose weights                              | Too many downloads from cellpose.org.                                                                                                      | Use `--cellpose_models_dir` with a pre-downloaded copy. See [Cellpose model weights](usage.md#cellpose-model-weights).                                                       |
| `cellpose_pretrained_model is neither a built-in model name nor an existing path` | A typo in the model name, or the custom model file does not exist.                                                                         | Use `cpsam_v2`, `cpsam`, `cpdino`, `cpdino-vitb` or an existing file path.                                                                                                   |
| `cellpose_models_dir does not exist`                                              | The directory has not been created.                                                                                                        | Create and fill it first. See [Cellpose model weights](usage.md#cellpose-model-weights).                                                                                     |
| `cellpose_model_type is no longer supported`                                      | The parameter was removed. Cellpose 4 ignores it.                                                                                          | Remove it. Use `cellpose_pretrained_model`.                                                                                                                                  |
| KRONOS2 fails and lists marker names not in the vocabulary                        | Channel names do not match KRONOS2 marker names.                                                                                           | Map them with `kronos_marker_mapping`, or exclude non-marker channels with `kronos_exclude_markers`. See [KRONOS2 embeddings](how-to/kronos2.md#fix-unmatched-marker-names). |
| KRONOS2 fails with "no such channel"                                              | A name in `kronos_exclude_markers` is not in the image. Channels in `remove_markers` are already removed when background subtraction runs. | Check the spelling and case. Do not list channels that `remove_markers` removes.                                                                                             |
| Mesmer fails to download its model                                                | `DEEPCELL_ACCESS_TOKEN` is not set.                                                                                                        | `nextflow secrets set DEEPCELL_ACCESS_TOKEN <token>`.                                                                                                                        |
| CellSAM fails because the mask contains no cells                                  | CellSAM found no cells, usually because of the wrong channels or a threshold that is too high.                                             | Check `nuclear_channel` and `membrane_channels`. Try a lower `cellsam_bbox_threshold`.                                                                                       |
| Samplesheet validation error                                                      | A column value does not match the samplesheet schema, a `sample` is repeated, or a row sets more than one method.                          | See [Samplesheet](reference/samplesheet.md).                                                                                                                                 |
| QuPath `StackOverflowError` when loading or exporting the GeoJSON                 | Some cell outlines have too many vertices.                                                                                                 | Re-run with `--smooth_masks true`, and `--smooth_method shapely` if needed.                                                                                                  |
| Task killed for memory (exit 137) or time (exit 140)                              | The task needs more resources.                                                                                                             | It is retried once with twice the memory. If it fails again, use a larger profile. See [Large and dense images](how-to/large-images.md).                                     |

## Results look wrong

- Cells appear flipped or rotated relative to the image (Mesmer): set
  `--mesmer_transpose_mask true`.
- Measurements show only one channel's values for every marker: check that the
  channel names in the image are what you expect. Images that store each
  channel as its own OME series (for example COMET `_fixed` exports) were read
  incorrectly by some steps of earlier versions.
- Masks from versions before 0.5.0 with more than 65,535 cells are truncated.
  Regenerate them.

## Getting help

Open an issue on [GitHub](https://github.com/WEHI-SODA-Hub/sp_segment/issues)
with the command you ran, the Nextflow version, the pipeline version, and the
`.command.err` of the failing task.
